# Anthropic 官方软件工程相关 Skills

本文件夹包含从 Anthropic 官方 skills 仓库中筛选出的与软件工程相关的 skills。

## Skills 列表

### 1. webapp-testing
使用 Playwright 与本地 Web 应用交互和测试的工具包，支持验证前端功能、调试 UI 行为、捕获浏览器截图和查看浏览器日志。

### 2. frontend-design
创建具有高设计质量的独特生产级前端界面，用于构建 Web 组件、页面、artifacts、海报或应用程序（包括网站、落地页、仪表板、React 组件、HTML/CSS 布局等），生成创意、精致的代码和 UI 设计，避免通用的 AI 美学。

### 3. web-artifacts-builder
使用现代前端 Web 技术（React、Tailwind CSS、shadcn/ui）创建复杂的多组件 claude.ai HTML artifacts 的工具套件，适用于需要状态管理、路由或 shadcn/ui 组件的复杂 artifacts。

## 使用说明

每个 skill 文件夹包含：
- `SKILL.md` - skill 的主要说明文档
- `scripts/` - 可执行脚本（如果有）
- `references/` - 参考文档（如果有）
- `assets/` - 资源文件（如果有）
- `examples/` - 示例文件（如果有）
