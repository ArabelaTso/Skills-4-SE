# Software Engineering Skills for Claude

This directory contains Claude skills specifically related to software engineering, development, and DevOps workflows. These skills enable developers to automate and streamline their software development lifecycle.

## Version Control & Code Hosting

### github-automation
Automate GitHub repositories, issues, pull requests, branches, CI/CD, and permissions via Rube MCP (Composio). Manage code workflows, review PRs, search code, and handle deployments programmatically.

### gitlab-automation
Automate GitLab project management, issues, merge requests, pipelines, branches, and user operations via Rube MCP (Composio). Manage CI/CD pipeline monitoring and branch management.

### bitbucket-automation
Automate Bitbucket repositories, pull requests, branches, issues, and workspace management via Rube MCP (Composio). Handle repository operations and code review workflows.

### sourcegraph-automation
Automate Sourcegraph code search and navigation operations through Composio's Sourcegraph toolkit via Rube MCP.

## CI/CD & Build Tools

### circleci-automation
Automate CircleCI tasks via Rube MCP (Composio): trigger pipelines, monitor workflows/jobs, retrieve artifacts and test metadata.

### buildkite-automation
Automate Buildkite CI/CD operations through Composio's Buildkite toolkit via Rube MCP for pipeline management and build automation.

### appveyor-automation
Automate AppVeyor continuous integration and deployment tasks for Windows, Linux, and macOS builds.

### appcircle-automation
Automate mobile CI/CD workflows with Appcircle for iOS and Android app builds and deployments.
